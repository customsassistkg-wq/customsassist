# Короткие запросы для работы с проектом

Не загружается автоматически. Копировать и подставлять `[…]`. Скиллы (`.claude/skills/`) задают порядок работы; знания — в `docs/`.

## Обычная задача

Сделай `[задача]`. Сначала прочитай CLAUDE.md и CURRENT.md, из docs/ — только то, что нужно этой задаче. После правки — проверки из раздела «Verification», `git diff --numstat` для больших файлов, запись в session.md. Не коммить.

## Review

Проведи глубокий review `[модуль]`. Сначала изучи текущую реализацию, зависимости и тесты. Не меняй код. Выдай findings по критичности с конкретными файлами и причинами.

## Review + Fix

Проведи review `[модуль]`, найди проблемы и исправь их. Сначала исследуй реализацию. Исправляй root cause, а не симптом. После изменения выполни релевантные проверки и self-review diff.

## Root cause

Исследуй `[проблема]`. Проследи data flow до первопричины. Не добавляй workaround до понимания причины. После подтверждения root cause внеси минимальное надёжное исправление и проверь регрессии.

## UI

Проведи глубокий UX/UI review `[страница]` (скилл `ui-review`). Проверь информационную иерархию, карточки, плотность, primary action, поиск, состояния, responsive, mobile, обе темы. Не ограничивайся субъективным дизайном: проверяй фактический DOM/CSS и браузер, замером.

## Калькулятор

Проведи полный review `[калькулятор]` (скилл `calculator-review`). Проследи расчёт от входных данных до итоговой суммы: source data, дата, валюта, единицы, ставки, коэффициенты, округление, exemptions, warnings, промежуточные значения, UI.

## ТН ВЭД / база

Проведи review `[база или findX]` (скилл `legal-source-audit`). Отдельно проверь authoritative data, search logic, prefix/exact matching, ввоз/вывоз/транзит/ЕАЭС, ограничения, лицензирование, техрегламенты, ссылки на источники. Не смешивай официальный факт и вывод модели.

## Нормативная сверка

Сверь `[база]` с действующей редакцией `[акт]` по первоисточнику (скилл `legal-source-audit`): редакция и дата, полнота по нумерации акта, набор кодов в обе стороны, обновление SOURCE_AUDIT тем же коммитом.

## AI-помощник

Прогони помощника на `[документы / вопросы]` (скилл `ai-assistant-review`). Раздели ошибки чтения, рассуждения и данных; закрывай на сервере, не в промте; читай сами ответы, не только галочки.

## Безопасность

Проведи ревью `[граница: вход / engine / админка / приватные файлы]` (скилл `auth-security-review`) по коду и снаружи (401/403/404), не пересматривая решения из docs/security-auth.md.

## Выкладка

Выложи `[что]` по скиллу `deploy`: резервная копия, SHA256 и синтаксис на сервере, порядок файлов, перезапуск при изменении server/, страница последней, проверка снаружи, запись в session.md и CURRENT.md.
