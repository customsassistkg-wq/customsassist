## Current architecture

- `tnved_checker.html` — markup, styles, login screen; served by Nginx at `https://customsassist.trade`. Holds no data.
- `server/private/base.js` (~12 MB) — every legal database and every `findX()`, `renderHtml`, `calcWarnings`, `lkPrefRates`, `BATCH_REQS`…, ending in `ENGINE_API`. **Server only.**
- `server/private/checker.js` (~380 KB) — the interface; served only through `/api/checker.js` to a verified, signed-in user; asks the base through `engine()` → `POST /api/engine` (per-account enumeration limits).
- `server/` — Express + PostgreSQL behind Nginx (TLS by Let's Encrypt, to 21.12.2026); Node listens on `127.0.0.1:3000` only. Sessions, admin panel, email verification, Turnstile, terms gate, НБКР rates, class decisions, payments ledger, xPay QR payments (switched off), «Обращения» (Cloudflare Email Worker → `/api/mail/inbound`), «Мои коды», subscription reminders, Telegram notifications to administrators.
- AI assistant — DeepSeek `deepseek-flash` through the Anthropic-compatible API (`AI_MODEL` in `.env`), server-side tools on the base; documents read at attach time (pdf.js in the browser; scans read in the EU by Google Vision and rebuilt from text, the image goes to the model only when the text cannot be trusted; Document AI only on disagreement). Claude can replace it by `.env` alone (`docs/ai-assistant.md`) — not switched.
- Administrators' dashboard `https://dash.customsassist.trade` — own Nginx block, same API; page `server/dash/index.html`, code `GET /api/dash.js` and data `GET /api/dash/data`, both `requireAdmin`.
- Дозор источников — `scripts/watch-sources.js` under `tnved-watch-sources.timer` (04:30 UTC daily): gov.kg, the registry, the ГТС quota counter, ЕС НСИ ЕАЭС, the ЕЭК trade-remedy register, ЕТТ files, ЕЭК Collegium and Council decisions, Kyrgyz publications, the editions of all 68 registry acts the base links to, base self-consistency; mails and Telegram to the administrators (`docs/backend-ops.md`, «Дозор источников»).
- Разбор находок из Telegram — «разобрать» fires a Claude Code routine that works on a `claude/watch-…` branch and reports back; «выложи» deploys `base.js`/`watch-sources.js` of that branch and fast-forwards `main` on GitHub and the mirror (`docs/ops-routine.md`). **Since the server moves `main`, `git pull` before working.**
- Монитор доступности — GitHub Actions `.github/workflows/uptime.yml` (01.10.2026): раз в 30 минут снаружи `/api/health`, `/` и сертификат; сбой — issue в репозитории и письмо GitHub, Telegram — если владелец добавит секреты (`docs/backend-ops.md`, «Монитор доступности…»).
- `mobile/` — Capacitor shell over the live site; the site is also installable as a PWA. `assets/` — every image the site serves; `assets/source/` is never deployed.
